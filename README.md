# ☕ Brewhaus — Artisan Coffee Landing Page

A fully responsive, single-page landing website for **Brewhaus**, a fictional artisan coffee brand. Built with pure HTML, CSS, and vanilla JavaScript — no frameworks, no build tools.

## ✨ Features

- **Fixed navigation bar** that changes style on scroll (backdrop blur + shadow)
- **Full-screen hero section** with animated overlay and call-to-action
- **About section** with image, brand story, and live statistics
- **Products section** showcasing 3 signature coffee blends with cards
- **Testimonials section** with customer reviews
- **Contact / Order form** with a success state message
- **Newsletter subscription** input
- Smooth scroll throughout the page
- Fully responsive — mobile, tablet, and desktop

## 🚀 Getting Started

No installation needed. Just open the file in a browser:

```bash
git clone https://github.com/YOUR_USERNAME/brewhaus-landing.git
cd brewhaus-landing
open index.html
```

Or deploy to **GitHub Pages**:

1. Push the repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch → `/ (root)`
4. Your site will be live at `https://YOUR_USERNAME.github.io/brewhaus-landing`

## 🎨 Design Decisions

- **Color palette** inspired by coffee tones: espresso `#1a0a00`, caramel `#c07d3a`, cream `#f5ede0`, gold `#d4a853`
- **Typography**: Playfair Display (headings) paired with Jost (body) for an elegant yet modern feel
- All styles use CSS custom properties for easy theming
